# Galactic Racing 9R-B.2 — watch player and pit-free v0.3

**Status: LOCAL PROTOTYPE, NOT DEPLOYED.** Branch: `feature/galactic-racing-9r-b2-watch`. Original 9R-A (v0.1) and 9R-B (v0.2) are intentionally preserved. This branch starts from camera improvements `a42da7f69f5a748bbb0c86661966491ba2d0ee34`, not from the free-AI branch.

## Scope and motivation

Human review found that the original large mobile timing tower obscured racing, the 460px portrait-height broadcast was too tall, the podium notice obscured racers, stage/replay distinctions were unclear, and pit repairs stopped cars at arbitrary places on the track.

The new **v0.3 pit-free engine** replaces regular pit repairs with timed effects and separately seeded **EXTERNAL** interference events. The legacy event engine is configuration-gated: absent v0.3 fields keep original RNG and old golden records unchanged. No real-time physics, betting influence or administrator-selected result was added.

The 3D track no longer renders pit scenery in v0.3. Temporary collisions, debris, magnetic disturbance and outside attacks are shown as events; the incident victim is eligible for high-priority automatic camera cuts. Old v0.1/v0.2 records can still be regenerated by their original simulators.

## Watch UI

- Desktop: YouTube-style 16:9 video player and **right-hand replay / season archive** pane.
- Mobile portrait: **16:9 video**, controls underneath, independently collapsible timing grid, season/replay listings further down. The desktop timing tower is not drawn over mobile video.
- Native fullscreen button on the broadcast player; separate controls visible in fullscreen.
- Three independent replay segments: **qualifying, main race, ceremony**. Replays restart/seek only within their own segment and auto-stop at the segment end. Default playback is 2x; cameras remain local spectator choices.
- Provisional podium and official post-DSQ podium explicitly labeled. On mobile, the ceremony caption/evidence is placed **below** the video.
- External-hazard highlight jump buttons focus the event without mutating the saved race.
- The seven-round season list is a **layout demonstration**, not a functional season calendar or historical result list. Credit, season service, scheduling and production /racing integration remain unimplemented.

## Local demo

From the repository root:

```bash
pnpm install --frozen-lockfile
npm ci --prefix prototypes/galactic-racing-v2 --ignore-scripts
pnpm racing:watch
```

Open `http://127.0.0.1:4173/`. To generate a static directory only run `pnpm racing:build:watch`; it creates `out/galactic-racing-watch/`. The uploaded CI artifact can be unzipped and served with `python -m http.server 4173 --bind 127.0.0.1`.

Historical `pnpm racing:prototype:v2` is deliberately still available. The watch build has its own `watch.html`, `watch.tsx` and `watch.css`.

## Tests and release boundary

- `pnpm test:racing` and `pnpm test:racing:v2` must preserve original golden values.
- `pnpm test:racing:v3` checks 200 full/summary meetings, seeded special DSQ, no PIT events/motion, external event types, replay UI presence and zero network.
- Local build and current GitHub Actions test workflow also run TypeScript, lint, app build, Chrome desktop/mobile screenshot QA and fullscreen interaction.
- v0.3 **40,000-race Monte Carlo remains separate from this UI review**. Run `pnpm racing:balance:v3 40000 output-file.json` before locking release balance; do not inherit v0.2 statistics.
- The downloaded replay JSON includes all future events, winners and special DSQ from the beginning, including before ceremony; production must use separately authorized result-visibility and once-only persistence.
- Test browser screenshots do not prove hardware acceleration or physical mobile device quality. Actual mobile UX and renderer performance need user-device review.
- No Production Site, D1, migration, Credit, AI Provider or main branch changes were authorized or made by this prototype.
