# 3-D: WebGL broadcast on the isolated 3-C contract

Base PR #6 edd322ab91a9f0e2ad24ba469b85fd2c107129dd. On /racing the live adapter shares the offline player's batched Vesper road and branch, racer/portrait geometry and SF podium set. It consumes public snapshots only. No Meeting, playback simulator, private director plan, full input, entropy, future standings or artifact handle is imported into the viewer. Three matches the prototype's pinned version. The old 3D prototype remains independent.

The server projects current route heading, grid positions from released qualifying ranks, timing-index GAP bounded by the confirmed tick, a current camera subject (leader retirement, authorized Ultimate, leader) and post-jump visibility. No end time, future target, next frame or projected winner is sent. Sparse pose interpolation is visual only: two confirmed samples, at most 500 ms, no prediction; large discontinuities, seek and phase changes snap. Live pause holds a local snapshot; return goes directly to server time. Archived seeks still require FINAL. The rider select overrides the director locally. Intro/grid, charge and Ultimate, retirement and the reclassified podium use the same disclosure boundaries as the 2D view. The live cut is simpler than the fully authored offline Phantom choreography.

WebGL2 success draws the track and cars; SVG remains a minimap. Renderer construction failure or context loss leaves the full SVG viewer, labelled 2D, while the feed continues. One RAF, nominal 30 Hz cap; context/material/texture/geometry teardown on unmount. No proof of hardware 30 FPS. Mobile QA is viewport emulation, not device QA.

Run with pinned dependencies: pnpm install --frozen-lockfile and node --import ./scripts/sites-env.mjs scripts/racing/preview-phase3c.mjs. Visit the printed loopback URL.
