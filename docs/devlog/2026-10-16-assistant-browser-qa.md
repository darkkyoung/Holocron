Playwright intercepts retrieval, generation and Credit visit API responses with synthetic contract-shaped data; no provider key, external provider call, live Google login, Production D1 or Credit mutation is involved. A second server checks the disabled COMING SOON route and News launcher.

`pnpm test:assistant-browser` runs a hydrated React smoke project first, then the existing acceptance project only if smoke passes. It covers 1440/1024/820/768/390/375/360px captures and bounds, Q&A/script selection and response rendering, fixed displayed prices, citations/copy, Guest/error/refund/cancellation, D.1 input consistency, keyboard/focus and reduced motion. A genuine tab transition test records a skip if headless Chromium does not actually report `document.visibilityState === 'hidden'`; synthetic visibility events are never counted as proof of a tab transition. Screenshots, smoke traces, traces on failure and the HTML report are Actions artifacts. The existing non-browser `test:*` scripts remain independent of Chromium; the workflow runs them and lint/tsc/build/diff-check after browser checks.

To run locally with a real browser and an isolated D1, use the workflow's `Prepare synthetic local D1` step, then `pnpm exec playwright install --with-deps chromium` and `pnpm test:assistant-browser`. Do not point the test server at Production. The workflow creates `.dev.vars` and `browser-qa/wrangler.local.json` only on its disposable runner and does not upload them.

All generated browser files now live outside the repository: CI sets `HOLOCRON_BROWSER_QA_ARTIFACT_DIR` from `$RUNNER_TEMP` in an early step; the local default is the OS temporary directory's `holocron-assistant-browser-qa` child. Viewport screenshots use `testInfo.outputPath`; Playwright's pinned implementation puts temporary `.playwright-artifacts-*` under `outputDir`. No Vite source watcher is disabled. Smoke-only command: `pnpm exec playwright test --config browser-qa/playwright.config.mjs --project=smoke`. The full command automatically honors the smoke dependency; do not use `--no-deps` for acceptance.
