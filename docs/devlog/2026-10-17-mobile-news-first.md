A disclosure open/close only changes native display state. Desktop retains the earlier Credit placement. Admin routes do not render this public status.

The News-only mobile search trigger and existing explorer share a small React context for *presentation openness only*. The query, category, Work ID, filtering, URL `?work=` handling and page reset stay in the original explorer. The single filter form stays mounted when closed, so its state survives reopening and viewport changes. Active filters have a compact visible status and reset action. The panel is a disclosure-like inline area, not a modal; it needs no backdrop/body scroll lock. The trigger exposes `aria-expanded`/`aria-controls`; opening focuses the native search input, and the in-panel result button closes it and returns to the list. Leaving the mobile breakpoint closes presentation only, preserving filters. All links remain normal anchors.
