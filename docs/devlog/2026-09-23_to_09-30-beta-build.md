- 없으면 가장 가까운 upcoming

이 규칙은 Phase 9B에서도 그대로 유지된다.

### Release date input bug
`616ffd2e — Fix Works release date input`

native controlled `input[type=date]`가 연/월/일 입력 도중 incomplete value를 빈 문자열로 내보내 state가 리셋되는 문제가 있었다.

해결은 native date input을 억지로 유지하는 것이 아니라 precision에 따라 직접 입력 UI를 나누는 것이었다.

- day → 연/월/일
- month → 연/월
- year → 연도
- unknown → 없음

저장 포맷은 기존 계약을 유지했다.

## Scheduler — Native Cron 실패에서 GitHub Actions로

자동 수집은 반드시 필요했지만 ChatGPT Sites deployment 경로에서 native Cron 사용이 원하는 형태로 지원되지 않았다.

처음에는 Phase 7 native Cron을 추진했지만 호스팅 제약 때문에 코드/Production을 억지로 변형하지 않고 중단했다.

그 다음 대안은:

```text
GitHub Actions schedule
→ authenticated POST
→ existing /api/scheduled/collect
→ shared collection-run service
→ collect()
→ D1
```

였다.

`11f2e4f9 — Add hosted scheduled news collection`

중요한 점은 scheduler 때문에 collection pipeline을 하나 더 만들지 않았다는 것이다. manual과 scheduled는 같은 service로 들어간다.

동시 실행은 expiring D1 lease로 막고 scheduler secret은 admin credential과 분리했다.

이후 실제 dispatch 검증을 거쳐:

- `5b8db3ad — Record Phase 7 production dispatch verification`
- `ecfabd62 — Complete Phase 7 production verification`

까지 진행됐다.

09-28에는 admin이 6시간 등 interval을 바꿀 수 있도록 schedule policy를 추가했고 GitHub Actions 자체는 hourly gate check를 수행하는 구조로 발전했다.

## Daily Quiz — Beta 전에 추가하기로 한 참여 기능

09-28 Daily Quiz가 큰 묶음으로 추가됐다.

처음 아이디어는 YouTube 커뮤니티 퀴즈처럼 가볍게 참여하는 기능이었다.

핵심 요구:

- 대표 이미지
- 객관식 선택지
- 선택지별 이미지 가능
- 즉시 정답/비율 공개
- 같은 browser session에서는 1회 참여
- 계정 시스템 불필요
- 관리자에서 작성/예약 공개

구현은 domain → migration → repository → service → API → public/admin UI 순으로 분리됐다.

대표 commit 흐름은:

- `d01be38d — Add daily quiz domain types`
- `a7e6782e — Add daily quiz data model`
- `68855cbf — Add daily quiz migration`
- `82f8c991 — Add public daily quiz participation API`
- `b2d6cd5c — Add public daily quiz experience`
- `8b57260e — Add quiz creation scheduling and management UI`

개발 중 요구도 바뀌었다.

한때 “항상 5개 선택지”로 고정했지만 이후 최종 제품은 2~5개로 정리되었고, 별도 제목 제거, 1:1 이미지 crop, hero link 등으로 발전했다.

`9c98b2d0 — Hide Daily Quiz answers before voting`

처럼 정답 데이터가 투표 전에 client로 새지 않도록 하는 보안/공정성 문제도 별도로 처리했다.
